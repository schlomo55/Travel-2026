## The work
1. **Coordinates.** Extend the verify:places flow so a CONFIRMED hit also yields its coordinate, and fold confirmed
   coordinates into the pipeline (a new checked-in data table, e.g. in `scripts/china/`, read by the spots/cards/bookings
   builders). A coordinate is kept ONLY when: the name agrees (Chinese or English, normalised) AND the hit lies within a
   sane radius of its anchor (the stop's coord / the city; justify per city — parks and scenic areas are large) AND its
   OSM class/type fits the place (a restaurant is not a bus stop). Two sources agreeing (OSM + Wikidata) is best; one
   clean OSM hit is acceptable; anything ambiguous → no coordinate. Verify the coordinates that already exist too (report,
   don't silently change; a clear error gets fixed with evidence). Cache every response in a git-ignored local cache so
   re-runs don't re-query.
2. **Category** (new optional `category` on Spot, ShowCard and Booking): one of
   `food · spa · sight · show · hotel · transport · medical · shopping`. Derive from the verified OSM tags
   (amenity=restaurant/cafe/fast_food → food; leisure=spa, amenity=public_bath, natural=hot_spring, massage shops → spa;
   tourism=attraction/museum/viewpoint, historic=*, leisure=park, natural=* → sight; amenity=theatre/arts_centre → show;
   tourism=hotel/guest_house → hotel; railway/aeroway/public_transport → transport; amenity=hospital/clinic/pharmacy →
   medical; shop=*, amenity=marketplace → shopping), else from the entity's own kind (hotel booking → hotel, flight/train →
   transport, spot kind food/show/sight/transport → same). The trip's own words win over OSM when they clearly say what
   the place is for the traveller (e.g. "Beijing Massage Hospital — blind massage / tuina" is **spa**, not medical — the
   MAPS6 boards show this case; "Huguosi TCM Hospital — bone-setting" is **medical**).
3. **Detail** (new optional `detail` string, ≤ 90 chars): ONE short line taken from the trip's OWN text where that place
   is described (the stop's options/blocks/recoBlocks prose, the show card's note) — verbatim or a trimmed clause, never
   composed, never from general knowledge. None when the text doesn't describe it. MAPS6.md lists 11 real examples.
4. **Types:** add `category?: PlaceCategory` and `detail?: string` to the model (optional — the real LTD app, built from
   main, must still import the new trip file: confirm its import validation ignores unknown fields, and say so).
5. **Seeds:** regenerate China (and the Israel test / template seeds only if they carry spots); `npm run verify:china`
   parity must hold; existing values (names, native, addresses, mapQuery, mapUrl) must not change — only added fields.
